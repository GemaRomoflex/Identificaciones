# Flex | Portal de Señalética y Visual Management

Sistema oficial de pedidos de identificaciones y señalética para planta de manufactura (Estándar REF-BR-100-A).

## Categorías soportadas
- 🏭 Estación de Planta (Estándar, con Flujo, Automática B29)
- 📦 Bines de Material (Simple y Min-Max)
- 🗑️ Tarjeta de Scrap
- 🔢 Número de Slot
- 🛒 Carro / Rack Viajero (5S WIP)
- 🪧 Letrero Aéreo
- 💻 Vinil para Laptop
- 🏢 Vinil de Oficina

## Características
- Previsualización en vivo exacta a formato de impresión.
- Generación y descarga automática de archivos PowerPoint (PPTX) listos para impresión.
- Soporte para códigos de barra y fotografías de componentes.
- Tablero Kanban y sistema de rastreo de pedidos.
